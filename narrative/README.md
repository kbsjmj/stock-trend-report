# narrative/ — 1절 원인 문구

파일명은 기준일 YYYYMMDD.json 입니다(예: 20261026.json). Claude가 그날 기사를 매체 3곳 이상 확인해 작성하고 push하면,
GitHub Actions가 발행합니다. 이 파일이 없으면 발행되지 않습니다.

스키마:
{
  "us": ["문장 1", "문장 2", "..."],   // 1-1 미국 증시 추세 요약 (자동 "데이터 시점" 문장이 맨 앞에 붙음)
  "kr": ["문장 1", "..."]              // 1-2 국내 증시 추세 요약
}

규칙
- 숫자는 data/report_data_기준일.json 값과 일치해야 합니다. 매체 값이 다르면 대표 출처와 차이를 주석으로 적습니다.
- HTML 태그를 넣지 않습니다(자동 이스케이프됨).
- 확인하지 못한 값은 '확인 불가'로 적습니다.
